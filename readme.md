🌳 Prime Factorization Tree App
An interactive, mobile-optimized web application designed to help students and teachers learn and explore Prime Factorization Trees in a fun, simple, and seamless way.
✨ Key Features
 Mobile-First Design: A flexible user interface tailored for smartphones and tablets with multi-touch support.
 Custom On-Screen Numpad: A responsive, built-in numeric keypad that pops up instantly when tapping analysis boxes, completely free of overlaps or blocked keys.
 Smart & Instant Validation: Automatic checking of input values and factor products with immediate visual alerts upon errors.
 Live Result Summary: Automatically calculates and displays the final prime factorization breakdown in a clean format (e.g., \bm{20 = 2 \times 2 \times 5}).
 Free Navigation (Pan & Zoom): Smooth panning, zooming in, and zooming out capabilities to easily handle large numbers and expansive factor trees.
 Localized Arabic Numerals: Full support for displaying numbers in Eastern Arabic numerals for an authentic educational experience.
🚀 How to Use
1. Enter the target number you want to factorize in the main input field at the top.
2. Click the "Start" (ابدأ) button to generate the root node of your number.
3. Tap any empty box or question mark ⁠?⁠ to open the numpad and input a factor.
4. Use the "Confirm" (تأكيد) button or tap anywhere outside the numpad to lock in the factor and progress.
5. Continue factoring until you reach Prime Numbers (which turn green and display a ✅ Prime badge).
🛠️ Technologies Used
 HTML5 / CSS3 / JavaScript (Vanilla): Built entirely with native web technologies without heavy external libraries for lightning-fast performance.
 SVG: Used to render sharp, scalable tree branches and connection lines dynamically at any zoom level.
 Google Fonts (Cairo): Utilized for clean, modern, and readable Arabic typography.
